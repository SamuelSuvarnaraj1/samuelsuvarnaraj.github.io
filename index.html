A pick and place cell controlled by a ladder-logic state machine on a Siemens S7-1500, written in TIA Portal and tested against a 3D cell in Factory I/O. Each step waits for the previous move to finish, and every fault has a defined way back to normal.

  • 10-step sequence, one memory bit per step, 26 ladder networks
  • Stop button, E-stop and a 20 second watchdog, each tested with a recovery run
  • Run on S7-PLCSIM and Factory I/O, not on physical hardware
